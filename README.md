# ARISE — личная система прокачки (Solo Leveling style)

Персональная платформа для отслеживания **только твоего** прогресса, вдохновлённая
аниме «Поднятие уровня в одиночку» (Solo Leveling / Arise). Тренировки с собственным
весом, питание, привычки — и всё это в виде «Системы» с уровнями, рангами и
характеристиками.

> Цель формы: тело **Найтвинга / Сон Джин-У** — V-образная спина, рельеф «Fight Club» (~10–12% жира).

## Что внутри

- **Окно Статуса** — уровень, ранг (E→S), опыт (XP), серия дней (streak).
- **Характеристики** — STR / VIT / AGI / INT / PER / SENSE, растут от выполненных квестов.
- **Тренировки** — сплит на 4 дня (День A: Тяга · День B: Жим + Ноги) с собственным весом,
  3 фазы прогрессии (Июнь → Июль → Август), переключение фаз и отметки выполнения.
- **Питание** — график приёмов пищи по времени, принципы «сушки», базовые рецепты с КБЖУ.
- **Привычки** — кодекс охотника (ранний подъём, чтение, вода, сон, без сахара и т.д.).
- **Онбординг** — оценка уровня по базовым упражнениям + выбор целевых групп мышц.

Весь прогресс хранится **локально в браузере** (`localStorage`) — никакого бэкенда,
данные только твои.

## Технологии

- **Next.js 14** (App Router) + **TypeScript**
- **Tailwind CSS** (тёмная «System»-тема)
- Структура **shadcn/ui** (`/components/ui`, `components.json`, alias `@/*`)
- `lucide-react` — иконки

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
```

Сборка прода:

```bash
npm run build && npm run start
```

## Про структуру shadcn и `/components/ui`

Проект уже настроен под shadcn: есть `components.json`, Tailwind с CSS-переменными,
TypeScript и алиас `@/*`. Компоненты shadcn по умолчанию ставятся в **`/components/ui`** —
именно поэтому интегрируемый `hero-ascii-one.tsx` лежит там. Эта папка важна, потому что:

1. CLI shadcn (`npx shadcn@latest add ...`) кладёт примитивы именно туда — общий путь
   избавляет от конфликтов импортов.
2. Алиас `@/components/ui/...` остаётся стабильным во всём проекте.
3. UI-примитивы отделены от смысловых компонентов приложения (`components/system`).

Если бы проект был пустым, инициализация была бы такой:

```bash
npx create-next-app@latest . --ts --tailwind --eslint --app --src-dir=false --import-alias "@/*"
npx shadcn@latest init      # выбрать components dir = components/ui
```
